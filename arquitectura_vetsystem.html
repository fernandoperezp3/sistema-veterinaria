2. Red & Proxy
DNS & CDN Cloudflare
  • Resolución DNS de dominio a IP pública
  • Terminación SSL/TLS (HTTPS Puerto 443)
  • Mitigación DDoS y Web Application Firewall
Servidor Nginx 1.24 Proxy Inverso
  • /static/ y /media/: Servidos directos
  • proxy_pass: Envío a Gunicorn (WSGI)
  • /api/v1/: Ruteo a Microservicios
  • /ws/: Proxy WebSockets Telemedicina
  • Compresión Gzip y HTTP/2
Seguridad Perimetral Security
  • Cabeceras HSTS, CSP y X-Frame
  • Protección contra CSRF y XSS
  • Rate Limiting contra fuerza bruta
3. Core Django
Servidor WSGI Gunicorn 21
  • Administrador de procesos Python Workers
  • Conexión mediante socket UNIX / TCP local

Núcleo Django 6.0 Monolito
  • Middlewares: Auth, Session, CSRF
  • apps.agenda: Citas y turnos
  • apps.clientes: Pacientes y dueños

Django ORM Data Layer
  • Mapeo Objeto-Relacional Modelos
  • Transacciones atómicas (ACID)
  • Cliente Celery / Despacho a Redis

Redis 7.x (En Memoria) In-Memory

Flujo de Comunicación E2E (Ciclo de Vida de la Petición: del Dominio a la Respuesta)
1
Solicitud Inicial

El usuario ingresa https://vetsystem.clinica.com en su navegador web.

2
Resolución DNS

El DNS (Cloudflare) traduce el nombre de dominio a la IP pública del servidor.

3
Handshake HTTPS

Conexión segura TLS 1.3 al puerto 443 de Nginx. Se verifica el certificado SSL.

4
Inspección Nginx

Nginx sirve estáticos directos (CSS/JS) o hace proxy_pass a Gunicorn.

5
Traspaso WSGI

Gunicorn toma la petición HTTP y la entrega al core de Django como entorno WSGI.

6
Middlewares

Django valida seguridad: sesión de usuario activa, permisos RBAC y token CSRF.

7
Enrutador URLs

urls.py ejecuta la vista del módulo correspondiente (ej. apps.medico).

8
Consulta ORM

La vista consulta o guarda datos mediante Django ORM contra MySQL (y caché Redis).

9
Microservicios

Si es tarea pesada (WhatsApp, SAT o PDF), se despacha en segundo plano a Redis.

10
Renderizado MVT

Django ensambla el HTML final con datos usando su motor de plantillas o responde JSON API.

11
Retorno de Respuesta

HTTP 200 viaja de regreso: Django → Gunicorn → Nginx → Navegador.

12
Pintado en Cliente

El navegador renderiza el DOM, aplica Bootstrap 5 y dibuja gráficos con Chart.js.
